# 📟 Terminal Portfolio - Command Reference

## Basic Commands

### `help` or `--help`
Shows all available commands with descriptions.

```bash
visitor@armin:~$ help
```

### `whoami`
Quick introduction - shows name, role, and location.

```bash
visitor@armin:~$ whoami
Armin Rezaiyan
Full-Stack Developer & CS Student
📍 Maryland, USA
```

### `about`
Detailed information about me, my background, and journey.

```bash
visitor@armin:~$ about
```

## Professional Information

### `experience` or `work`
Displays all work experience with company, role, period, and descriptions.

```bash
visitor@armin:~$ experience
```

### `education`
Shows educational background including degrees and institutions.

```bash
visitor@armin:~$ education
```

### `skills`
Lists technical skills organized by category:
- Languages
- Frameworks
- Tools
- Interests

```bash
visitor@armin:~$ skills
```

### `contact`
Shows all contact information including email, LinkedIn, and GitHub.

```bash
visitor@armin:~$ contact
```

### `resume`
Information about accessing the resume.

```bash
visitor@armin:~$ resume
```

## System Commands

### `clear` or `cls`
Clears the terminal screen.

```bash
visitor@armin:~$ clear
```

### `ls`
Lists available "files" (hint: try it!)

```bash
visitor@armin:~$ ls
```

### `pwd`
Shows the current directory path.

```bash
visitor@armin:~$ pwd
```

## Tips & Tricks

1. **Arrow Keys**: Use ↑ and ↓ to navigate through command history
2. **Any Help Flag**: Add `--help` or `-h` to any command for the help menu
3. **Easter Eggs**: Try some classic Unix commands like `sudo`, `exit`, etc.
4. **Case Insensitive**: Commands work in any case (HELP, help, HeLp)
